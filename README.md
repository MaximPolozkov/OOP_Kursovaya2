# **Проект для получениия вакансий с hh и записи их в JSON файл**

Что бы запустить проект, нужно перейти в модуль main.py.


В проекте сделаны такие модули как, получение вакансии с hh через API,
модуль headhanter_api.py. 

Созданы абстрактные методы, для работы с вакансиями API vacancy_api.py, 
метод для записи данных в бд data_server.py.

Создан модуль vacancy.py для представления и сравнения вакансий,
модуль для создания, поиска и удаления вакансии из JSON файла json_server.py.

Весь функционал протестирован с помощью pytest.
